# Ground Beam Progress Label Handbook v0.1

สถานะ: Draft สำหรับ Calibration รอบแรก - ห้ามนำ Annotation ชุดทดลองไปเป็น Test Ground Truth

## 1. หน่วยที่ติด Label

- หน่วยหลักคือ Beam Segment หนึ่งช่วงระหว่างจุดตัด Grid ที่ติดกัน
- Segment อ้างอิง `sheet_id`, Grid ต้นทาง/ปลายทาง และความยาวจากแบบ
- ทุกหลักฐานต้องมี `capture_date`, `timestamp_ms` และสถานะการมองเห็น
- ถ้ายัง Localize วิดีโอเข้ากับแบบไม่ได้ ห้ามเดาว่าเป็น Segment ใด ให้ใช้ `CANNOT_LOCALIZE`

## 2. Progress 0-100

Progress ของคานคอดินใช้ Milestone ตามลำดับกิจกรรมในแผน และคำนวณความคืบหน้าภายในช่วงจากสัดส่วนความยาวที่ทำเสร็จ

| Progress | Milestone ที่ต้องเห็น |
|---:|---|
| 0 | ยังไม่เริ่ม หรือเห็นเฉพาะดิน/ร่องขุดโดยไม่มี Lean concrete |
| 20 | Lean concrete ของช่วงเสร็จ |
| 40 | เหล็กคานประกอบและวางครบช่วง |
| 60 | แบบคานติดตั้งครบและพร้อมเท |
| 80 | เทคอนกรีตครบ แต่ยังไม่ถอดแบบ/ยังบ่ม |
| 100 | ถอดแบบแล้วและคานช่วงนั้นผ่านการตรวจด้วยสายตา |

ตัวอย่าง: ถ้า Lean concrete เสร็จเต็มช่วงและเหล็กเสร็จครึ่งช่วง ให้คิด `20 + (20 × 0.5) = 30%`

## 3. Visibility status

| Status | ความหมาย | ใช้คำนวณ Actual หรือไม่ |
|---|---|---|
| `VISIBLE` | เห็น Segment เพียงพอตัดสิน | ใช้ |
| `PARTIAL_VIEW` | เห็นบางส่วน; รายงาน Confidence ต่ำ | ใช้เมื่อผู้ตรวจยืนยัน |
| `OCCLUDED` | ถูกบังด้วยวัสดุ คน เครื่องจักร หรือดิน | ไม่ใช้ |
| `BLURRY` | ภาพสั่น/เบลอจนตัดสินไม่ได้ | ไม่ใช้ |
| `CANNOT_LOCALIZE` | เห็นงานแต่ยังจับคู่ Segment ในแบบไม่ได้ | ไม่ใช้ |
| `NOT_IN_FRAME` | Segment ไม่อยู่ในภาพ | ไม่ใช้ |

ห้ามแปลง `OCCLUDED`, `CANNOT_LOCALIZE` หรือ `NOT_IN_FRAME` เป็น 0% เพราะจะทำให้ Actual ต่ำกว่าความจริง

## 4. Evidence rules

- ใช้หลักฐานอย่างน้อย 2 Keyframes ต่าง Timestamp ต่อ Segment เมื่อเป็นไปได้
- ถ้าหลักฐานขัดกัน ให้ใช้ภาพที่ใหม่กว่าเฉพาะเมื่อ Localize เป็น Segment เดียวกันได้
- เหล็กที่วางกองอยู่ใกล้ร่อง แต่ยังไม่ประกอบ/วางในแนวคาน ไม่นับเป็น Rebar complete
- Lean concrete ต้องเห็นต่อเนื่องในช่วง ไม่ใช่เพียง Concrete pad ของฐานราก
- Formwork ต้องเห็นสองด้านและมีสภาพพร้อมเท จึงนับ 60%
- Concrete ที่เพิ่งเทแต่ยังไม่ยืนยันถอดแบบ ห้ามนับ 100%

## 5. Trial review of four captures

จาก Keyframe กลางวิดีโอวันที่ 23, 25, 26 และ 28 ธันวาคม 2025 เห็นลำดับโดยรวมจากงานร่อง/ฐาน ไปสู่ Lean concrete และการประกอบเหล็กคานมากขึ้น แต่ยังไม่มี Start Point และ Path ที่ผูกกับ Grid จึงให้สถานะ `CANNOT_LOCALIZE` สำหรับ Segment รายตัวในรอบนี้

ไฟล์ `ml/annotations/beam-segments-v0.1.json` มี 10 Segment ทดลองบนแนว Grid B และ C เพื่อทดสอบ Schema และหน้าแก้ไขเท่านั้น ค่า `training_eligible=false` จนกว่าผู้ใช้จะตรวจตำแหน่งบน Web

## 6. Quality control

- ผู้ติด Label คนที่ 1 และคนที่ 2 ต้องใช้ Handbook ฉบับเดียวกัน
- สุ่มตรวจซ้ำอย่างน้อย 20% ของ Segment ที่ใช้ทดลอง
- บันทึกเวลาเริ่ม/จบการ Review เพื่อรายงานเวลาคน
- ก่อนใช้เป็น Ground Truth ต้องได้ข้อตกลง Progress ต่างกันไม่เกิน 10 percentage points หรือส่งให้ผู้ตัดสินคนที่ 3
- ชุด Test ต้องล็อกก่อน Tune และห้ามนำผล Test กลับไปแก้ Threshold
