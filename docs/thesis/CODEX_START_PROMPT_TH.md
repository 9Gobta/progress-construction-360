# Prompt เริ่มงานสำหรับ Codex ของผู้ทำเล่ม

คัดลอกข้อความด้านล่างไปเปิด task ใหม่ใน Codex หลังจากเปิด Local Project นี้แล้ว

---

คุณช่วยผมทำเล่มจบของโครงการ Progress Construction 360 โดยทำงานเฉพาะเอกสาร ไม่แก้
application code, migration, database, `.env` หรือข้อมูล Virtual Tour/3D warp point

ก่อนเริ่มให้คุณอ่าน `AGENTS.md`, `PROJECT_CONTEXT.md`, `THESIS_HANDOFF.md`,
`docs/planning/00-planning-index.md`,
`docs/planning/09-scope-v2-human-structural-bim.md`,
`docs/development/09-current-acceptance-status.md` และ `docs/thesis/README.md`

ขอบเขตปัจจุบันคือใช้ AI/CV ช่วย Localization แต่ Progress งานโครงสร้างต้องให้คนตรวจ
และยืนยันจากหลักฐานภาพ 360 ห้ามนำผล AI Progress รุ่นเก่ามาเขียนเป็นความสามารถปัจจุบัน
ห้ามแต่งตัวเลข ผลทดลอง การอ้างอิง หรือข้อสรุปของอาจารย์ หากหลักฐานไม่พอให้เขียน TBD
และบอกว่าต้องขอข้อมูลอะไรจากเจ้าของโปรเจกต์

ผมจะแนบคลิปเสียงที่คุยกับอาจารย์ ให้ถอดและสรุปโดยแยกเป็น 4 ส่วน:
1) สิ่งที่อาจารย์สั่งชัดเจน
2) ข้อเสนอหรือแนวคิดที่ยังไม่ยืนยัน
3) งานที่ต้องทำและผู้รับผิดชอบ
4) ช่วงเสียงที่ไม่ชัดและต้องถามซ้ำ

จากนั้นให้เสนอสารบัญและแผนเขียนเล่มที่ผูกกับหลักฐานใน repository ก่อนเริ่มเขียนจริง
ทุกครั้งที่เขียนให้อ้างชื่อไฟล์ต้นทาง และแก้เฉพาะ `docs/thesis/`,
`docs/advisor-meetings/`, `docs/system-design/` หรือ `docs/test-results/`

---

## Prompt งานรอบถัดไป

หลังสรุปเสียงแล้ว ใช้ข้อความนี้:

> จากสรุปอาจารย์และหลักฐานใน repository ช่วยเลือกหัวข้อที่พร้อมเขียนที่สุดหนึ่งหัวข้อ
> ทำ evidence map ก่อนว่าแต่ละย่อหน้าจะอ้างไฟล์ใด แล้วร่างลงใน `docs/thesis/`
> ห้ามเติมข้อเท็จจริงที่ไม่มีหลักฐาน และรวมคำถามที่ต้องถามเจ้าของระบบไว้ใน
> `docs/thesis/open-questions.md`
