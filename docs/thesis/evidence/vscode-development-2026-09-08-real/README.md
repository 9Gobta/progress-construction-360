# หลักฐานภาพจริงสำหรับหัวข้อ 3.6

ภาพชุดนี้บันทึกจากหน้าต่าง Visual Studio Code ที่เปิดโครงการ Progress Construction จริงเมื่อวันที่ 8 กันยายน 2569

- `01-vscode-project-explorer.png` — เปิดโครงการและตรวจโครงสร้างไฟล์ด้วย Explorer
- `02-vscode-source-code.png` — ตรวจสอบซอร์สโค้ดส่วน BIM Viewer
- `03-vscode-development-terminal.png` — ตรวจสถานะบริการเว็บและ API ใน Integrated Terminal
- `04-vscode-quality-checks.png` — ผล `lint:web`, `typecheck:web` และ `build:web` ซึ่งออกด้วยรหัส 0
- `05-vscode-automated-tests.png` — ผลชุดทดสอบเว็บ 7 กรณีผ่านทั้งหมด
- `06-vscode-git-traceability.png` — สถานะ Working Tree และสรุป Git diff สำหรับตรวจสอบย้อนกลับ
