# Test-result evidence

Use one Markdown file per reproducible test run. Record:

- date and operator;
- Git commit or working-tree note;
- environment and relevant versions;
- exact command or manual procedure;
- input capture/dataset IDs;
- expected and observed result;
- pass/fail/review-required decision;
- links to sanitized screenshots or result tables.

Confidence is not accuracy. A localization acceptance claim requires labelled
ground truth and the stated evaluation procedure.
