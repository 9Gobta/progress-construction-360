# Scope v2 — Human Structural Progress + BIM Compare

วันที่ปรับขอบเขต: 27 สิงหาคม 2026

ยืนยันใช้ขอบเขตนี้อีกครั้ง: 2 กันยายน 2026

## ขอบเขตที่ใช้พัฒนาต่อ

- ใช้ Capture 360 องศาเป็นหลักฐานตรวจหน้างาน
- Progress 0–100% กรอกโดยคนเท่านั้น
- ตรวจเฉพาะงานโครงสร้างทั้งหมด ไม่รวมงานสถาปัตยกรรม
- เส้นทางกล้องปรับด้วยคนเมื่อวางบนแปลนไม่ตรง
- สมาชิกหลายคนเข้าตรวจโครงการเดียวกันได้
- เชื่อมโมเดลโครงสร้างจาก Revit เพื่อแสดงเทียบกับภาพ 360 แบบเคียงข้างกัน

## ขอบเขต AI ที่ยังคงใช้

- ใช้ AI/CV ช่วยสร้างเส้นทางและระบุตำแหน่งภาพ 360 บนแปลน
- ไม่ใช้ AI จำแนกขั้นงาน คำนวณเปอร์เซ็นต์ หรือสร้าง Actual Progress
- API สำหรับรัน/ประเมิน AI Progress ถูกยกเลิกและตอบสถานะ `410 Gone`
- Prediction เดิมคงอยู่ในฐานข้อมูลเพื่อ Audit เท่านั้น ไม่แสดงในหน้า Progress, Dashboard หรือ CSV

## แหล่งข้อมูล Actual ที่เป็นทางการ

1. ผู้ตรวจเลือกองค์ประกอบหรือรายการงานบนแปลน
2. ตรวจภาพ 360 ณ Capture Date ที่เลือก
3. บันทึกขั้นงาน/เปอร์เซ็นต์และภาพหลักฐาน
4. ระบบเก็บผู้กรอก เวลา และประวัติแบบไม่เขียนทับ
5. Dashboard และ CSV ใช้เฉพาะค่าที่ผู้ใช้ยืนยัน

## รูปแบบ BIM สำหรับต้นแบบ

ไฟล์ต้นทางคือ Revit (`.rvt`) แต่เว็บต้นแบบรับ IFC เพื่อให้เปิดใน Browser ได้โดยไม่ต้องติดตั้ง Revit ที่เครื่องผู้ตรวจ

ไฟล์ Revit ล่าสุดที่พบ:

`D:\Project\Project ปี 3 เทอม 1\หอพัก 4 ชั้น\2026\RR.rvt`

ขั้นตอน Export:

1. เปิดไฟล์ใน Revit และเปิด 3D View ที่แสดงเฉพาะโมเดลโครงสร้าง
2. เลือก File → Export → IFC
3. ใช้ IFC2x3 Coordination View 2.0 เพื่อความเข้ากันได้กับเว็บต้นแบบ
4. เปิด Export only elements visible in view หากต้องการตัดงานสถาปัตยกรรมออก
5. เปิด Export base quantities และเก็บ Building Storey/Level
6. บันทึกเป็น `Data/bim/structural-model.ifc`

## BIM Compare ที่ต้องพัฒนา

- จอซ้าย: ภาพ 360 ณ Warp Point ที่เลือก
- จอขวา: โมเดล IFC มุมมอง 3D
- เลือกชั้นและซ่อน/แสดงหมวด เสา คาน พื้น ฐานราก และบันได
- ปรับตำแหน่ง หมุน และซูมโมเดลได้
- บันทึกมุมมองโมเดลที่สัมพันธ์กับ Warp Point
- เปิด/ปิด BIM Compare ได้จากหน้า Capture Viewer

## เกณฑ์รับงาน

1. ผู้ตรวจสองบัญชีเปิดโครงการเดียวกันและบันทึก Progress ได้
2. ผู้ชมแก้ Progress ไม่ได้
3. หน้า Progress และ Dashboard แสดงเฉพาะงานโครงสร้างและไม่มีผล AI Progress
4. เปิด Capture แล้วแสดงภาพ 360 และโมเดล IFC แบบเคียงข้างกันได้
5. เลือกชั้นในโมเดลและบันทึกมุมมองอ้างอิงของแต่ละ Warp Point ได้
