# Wireframes

> **Scope v2:** Wireframe ที่แสดง AI Actual, Confidence หรือ AI Review Queue เป็นประวัติ Baseline 1.0 หน้าปัจจุบันแสดง Planned และผลตรวจจริงโดยผู้ใช้เท่านั้น

## ระบบประเมินความก้าวหน้างานก่อสร้างจากวิดีโอ 360 องศา

| รายการ | ค่า |
|---|---|
| สถานะเอกสาร | Approved - Round 2 |
| เวอร์ชัน | 1.0 |
| วันที่ | 21 สิงหาคม 2026 |
| รูปแบบเป้าหมาย | Desktop-first, ภาษาไทย |

## 1. แนวทางหน้าตาและการใช้งาน

- ใช้โครงสร้างแอปแบบ Sidebar + Top bar คล้ายเครื่องมือจัดการโครงการ
- Floor Plan และภาพ 360 เป็นพื้นที่หลัก ไม่ใช้ Dashboard cards จำนวนมากโดยไม่จำเป็น
- Planned, AI Actual และ Verified Actual ใช้ชื่อกำกับเสมอ ไม่สื่อความหมายด้วยสีอย่างเดียว
- ทุกหน้าที่ประมวลผลต้องมี Loading, Empty, Error และ Retry state
- ปุ่มหลักหนึ่งปุ่มต่อกลุ่มงาน เช่น `ยืนยัน Import` หรือ `เริ่มประมวลผล`
- UI รุ่นแรกเป็นภาษาไทย โดยคงชื่อเทคนิค เช่น Capture, Tracker และ Confidence เมื่อช่วยให้สื่อสารในเล่มง่ายขึ้น
- ไม่คัดลอกตราสินค้า สี หรือหน้าจอของ OpenSpace โดยตรง แต่ใช้ Workflow ประเภทเดียวกัน

- ตารางเลื่อนแนวนอนได้
- Floor Plan และ 360 Viewer เปลี่ยนเป็น Tabs แทนการบีบสองคอลัมน์

### 18.3 ทุกหน้าต้องมี

- Loading state
- Empty state
- Error state ที่บอกวิธีแก้
- Permission denied state
- Success feedback หลังการบันทึก

## 19. จุดที่ขออนุมัติรอบที่ 2 - Wireframes

1. ใช้ Sidebar ตามเมนูที่แสดงใน App Shell
2. หน้า Overview ใช้ Setup Checklist เป็นจุดเริ่มต้น
3. Schedule Import เป็น Wizard 4 ขั้น
4. Upload Capture แยก Metadata และ Start Point เป็นสองขั้น
5. ผู้ใช้คลิกจุดเริ่มต้นเพียงครั้งเดียว ไม่มีตัวเลือกทิศหรือวาด Path
6. Capture Explorer แบ่ง Floor Plan กับ 360 Viewer ครึ่งหน้าจอ
7. AI Review แสดง Queue, แบบ, Evidence, AI Result และ Human Result ในหน้าเดียว
8. Dashboard แสดง Planned, AI Actual, Verified, Variance และ Coverage พร้อมกัน
9. CSV Export อยู่ทั้งหน้า Dashboard และ Reports
10. UI รุ่นแรกเป็นภาษาไทยแบบ Desktop-first
