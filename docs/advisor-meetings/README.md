# Advisor meeting records

Store only reviewed, sanitized meeting summaries in this directory.

Recommended filename: `YYYY-MM-DD-summary.md`

Each summary should separate:

1. confirmed advisor instructions;
2. tentative suggestions;
3. action items and owners;
4. unclear audio/questions to confirm;
5. impact on thesis scope or system scope.

Raw audio and unsanitized transcripts belong in `private/`, which Git ignores.
Send the recording to the teammate through a private file-sharing channel.
